# Runforge — AI Agent Runs Dashboard

Frontend-интерфейс страницы **Runs** для мониторинга запусков AI-агентов, фильтрации по статусам, поиска и просмотра логов выполнения.

> **Live Demo:** `https://runforge-ochre.vercel.app/`

---

## Стек технологий

* **React 19 + TypeScript** — компонентная архитектура и строгая типизация моделей данных.
* **Vite** — сборка проекта и dev-сервер.
* **Tailwind CSS v4** — utility-first стилизация в палитре Runforge и адаптивность.
* **Lucide React** — минималистичные иконки для статусов и элементов управления.
* **Vitest + React Testing Library** — интеграционные автотесты ключевых пользовательских сценариев.

---

## Установка и запуск

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск в режиме разработки
npm run dev

# 3. Сборка production-версии
npm run build

# 4. Предпросмотр собранного бандла
npm run preview

# 5. Запуск всех тестов
npm run test
```

--- 
## Покрытые тесты

1. Фильтрация списка запусков по статусу
2. Поиск по названию запуска или репозиторию
3. Открытие панели деталей по клику и закрытие по клавише ```Escape```
4. Отображение пустого состояния при отсутствии совпадений и сброс фильтров.  
5.Обработка ошибки загрузки данных и восстановление списка по кнопке "Повторить"  
6. Синхронизация выбранных фильтров и поискового запроса с query-параметрами URL.

## Реализованный функционал
* Список запусков: отображает название запуска, репозиторий, ветку, визуально различимый статус (цвет + иконка + текстовая подпись), дату создания и длительность (с корректной обработкой отсутствующей длительности или результата).
* Совместная фильтрация и поиск: фильтрация по статусам работает одновременно с живым поиском по названию запуска или репозиторию.
* Детали запуска: при клике на строку/карточку (или нажатии Enter / Space при фокусе с клавиатуры) открывается боковая панель с полной информацией, результатом выполнения (если он есть) и логами в терминальном стиле.
* Состояния интерфейса:   
  1)  Загрузка: скелетон-плейсхолдеры на время выполнения mock-запроса (~600 мс).   
  2) Ошибка: экран с описанием проблемы и кнопкой «Повторить» (в шапке есть переключатель Simulate API error для быстрой проверки этого состояния).   
  3) Пустой результат: информативное сообщение и кнопка «Сбросить фильтры».   
* Адаптивность: на десктопе список отображается в виде таблицы, на мобильных экранах (от 360px) автоматически перестраивается в компактные карточки без горизонтального скролла.

* Сортировка: по дате создания (сначала новые / старые) и по длительности выполнения.

* URL-фильтры: состояние выбранного статуса, поиска и сортировки сохраняется в query-параметрах (?status=...&q=...&sort=...) и восстанавливается при перезагрузке страницы.

* Управление с клавиатуры: навигация по списку через Tab / Enter и закрытие панели деталей по Escape
